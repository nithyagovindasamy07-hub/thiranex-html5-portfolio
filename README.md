
# HTML5 Semantic Structure & Accessibility

## Project Overview
A multi-page personal portfolio website built using semantic
HTML5 and CSS. The project demonstrates accessible navigation,
structured content, SEO-friendly metadata and a keyboard-friendly
contact form.

## Pages
- Home: Introduction and interests
- About: Education and career goals
- Projects: Project descriptions
- Contact: Accessible contact form

## Technologies Used
- HTML5
- CSS3
- Semantic HTML elements
- ARIA attributes
- Responsive web design

## Accessibility Features
- Semantic page structure
- Skip-to-main-content link
- Labels for form fields
- Keyboard-visible focus indicators
- Responsive layout
- Accessible navigation labels

## How to Run
1. Download or clone this repository.
2. Open index.html in a web browser.
3. Navigate through the Home, About, Projects and Contact pages.

## Note
The contact form is a front-end demonstration and does not
send messages to a server.
